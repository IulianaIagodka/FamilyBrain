# FamilyBrain

**Stop being the family memory.**

FamilyBrain helps couples and families share the mental load — not just share a calendar.

## Promise

One person often remembers everything: school messages, appointments, forms, gifts, bills, and the hundred small things that keep a household moving. Even when tasks are “shared,” someone still has to notice them, turn them into tasks, and remind everyone else.

FamilyBrain reduces that invisible planning work.

## Core idea

**Responsibility + ownership**

Every responsibility has:

- a title
- an owner (You / Partner / Shared / Unassigned)
- an optional due date
- source/original information
- status
- optional child/family member
- optional notes

Capture first. Structure second. Ownership third.

## MVP screens

1. **Home** — Needs attention, Mine, Partner, Shared
2. **Inbox / Capture** — paste or type first; confirm suggestions before saving
3. **Responsibility details** — clear ownership, quick reassignment
4. **Weekly overview** — visibility, not a score
5. **Mental load overview** — who currently carries each area
6. **Family members**
7. **Settings / history**

## Run

```bash
npm install
npm run web      # or npm start / npm run ios / npm run android
```

## Notes

- Text and paste capture are fully supported in v1.
- Photo, voice, and richer AI extraction are structured to plug into the same Inbox confirmation flow later.
- Suggestions never silently create responsibilities without confirmation.
